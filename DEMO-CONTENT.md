# Demonstration content

The public site displays sample researcher information and illustrative publications, achievements, events and gallery placeholders until Supabase content is configured. None of the sample achievements or papers are factual.

If your Supabase database already has content, the site uses those records. To populate the connected database with the same examples, run `supabase/demo-seed.sql` in the Supabase SQL Editor. The script replaces existing portfolio content; back up any real content first.

Replace the sample identity and links in the admin dashboard before publishing a real academic portfolio.
