# Doctoral Spectrum — GitHub Pages Edition

Bilingual English/Arabic doctoral e-portfolio with orange, red and blue branding and a Supabase-backed single-administrator dashboard.

**Start with `SETUP.md`.** This is a static GitHub Pages application, not an installable WordPress theme.

For security, no administrator password is included. Create the admin account in Supabase and authorize its user ID with `supabase/authorize-admin.sql`.
